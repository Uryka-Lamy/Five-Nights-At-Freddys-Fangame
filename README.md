## 项目简介

使用 Unity 2022.3 (Built-in RP) 纯代码复刻的 FNAF 1 守夜玩法：

- 6 间夜 + 自定义夜（AI 等级可调 0~20）
- 四玩偶 + 隐藏彩蛋：兔（西线随机）、鸡（东线、厨房噪音）、熊（东线固定、监控压制、停电处刑）、狐狸（海盗湾耐心制、撞门）
- 监控系统（雪花屏遮挡、移动噪点）、双门/门灯、电力管理、停电剧本（神曲 + 熊闪烁双眼）
- 音效闪避系统、每夜电话语音（可挂断）、按夜 AI 递增（原版机制）

## 运行方式

1. 使用 **Unity 2022.3.62f3c1** 打开项目
2. 菜单栏 `FNAF → 一键完成全部`（程序化生成全部场景与配置）
3. `Ctrl+S` 保存场景后点击 Play 即可游玩

## 目录结构

```

├── Editor/    # 程序化生成器（场景/UI/配置一键生成）
```
